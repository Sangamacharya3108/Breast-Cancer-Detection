About the project

Breast cancer detection from histopathology using deep learning (CNN & Transfer Learning).

Overview

This application demonstrates binary classification of breast histopathology images into Benign (non-cancerous tissue patterns) and Malignant (cancerous patterns), using Deep Learning (Convolutional Neural Networks & Transfer Learning) trained on labeled datasets such as the IDC (Invasive Ductal Carcinoma) patch collection on Kaggle.

The web layer is built with Flask and a responsive Bootstrap 5 frontend. Uploaded images are validated before inference — only genuine histopathology slides are accepted.

Models & approaches

  • Custom CNN

    Stacked convolutional blocks with pooling and dense layers—baseline feature learning on histopathology patches.

  • ResNet50

    Residual connections allow training of very deep networks; ResNet50 is a proven transfer-learning backbone for medical image analysis.

  • EfficientNetB0

    Compound scaling balances depth, width, and resolution—accurate and efficient for histopathology transfer learning.

  • MobileNetV2

    Lightweight inverted-residual backbone enabling fast inference for real-time histopathology prediction on limited hardware.
